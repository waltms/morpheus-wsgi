We are excited to include the time-honored Morpheus parser here as a fall-back or second opinion for our own static database, which is far from offering parses for all words in Greek literature. Morpheus was originally written by Gregory Crane, Joshua Kosman, and Neel Smith, and has long been a primary component in the Perseus project at Tufts, and in many places beyond. This version comes from The Perseids Project Tools on GitHub. Web interface by Walter M. Shandruk. Note: please report incorrect parses and other malfunctions to us.
Do bear with us as we try to understand this tool better! Occasional restarts will happen as we try new tweaks to the system.

Here are some persistent bugs in the system. Solutions welcome:
  • Dialect tags accumulate rather than filter: an Attic ending is happily allowed on an Aeolic stem, say. As a result, while I have added a number of Aeolic stems, I have not added Aeolic -ais, -ois endings for the accusative plural.
  • Iota adscripts are too hip for this system that was first built in the 1980s. Rewrite forms with a iota subscript or try the form without accents if at first you don't get a result.
  • Apostrophe supplements are given regardless of vowel length. Accent changes due to apostrophe are not systematically applied.
  • Not a bug but a feature: I have made an effort to recognize legitimate compound verbs. Compounds found in later authors are less likely to be found in LSJ, but DGE, Pape and Bailly often have more to offer, but with the inverse function in Logeion you can easily get back to the simplex verb as well.

    • Finally, a plea: this parser, like the dictionaries, needs critical users to improve! Please send comments via the problem reports! Many thanks.
